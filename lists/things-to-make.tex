\item n-gram corpus: either of my own, English as a whole, or some other thing. Make for n ranging from 1-5.

In print hand, theoretically monograms\footnote{n=1} should be sufficient, because there's nothing that adjacent letters necessarily need to do with each other.  
However, I also make symbols such as \&, and I write with as a superscript w and /.  
In the past, I also shared the cross in a t if doubled up (as in attack).

It's also potentially nice for touch type practice? Though that might be more difficult, because it would require keybr to support me having my custom set or else making a custom set.

\item Some way to have my blog taggable/ metadata'd
